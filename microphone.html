Enable voice input

This permission is for YouTube Learn. Allowing YouTube to use your microphone does not enable it for this extension.

Click the button below, then choose Allow in Chrome's prompt. This check releases the microphone immediately and does not save or send a recording.

If access was previously blocked, open the page's microphone/site permission control and allow access for this extension. Also check Windows Settings → Privacy & security → Microphone → Let desktop apps access your microphone.
